# Triggers

A trigger runs stored logic automatically on a table write. It fires once per affected row, silently.

<Steps>

### Pick the timing

`BEFORE` validates and edits the incoming row. `AFTER` audits the finished row.

### Pick the event

`INSERT`, `UPDATE`, or `DELETE`. Each exposes different row images.

### Write the body

Act on `NEW` and `OLD`. Test both the firing path and the quiet path.

</Steps>

## Timing

<Tabs items={['BEFORE', 'AFTER']}>
  <Tabs.Tab>
    Runs before the row lands. Can edit `NEW` values and abort with `SIGNAL`.

    ```sql filename="before" copy
    CREATE TRIGGER t_before_insert BEFORE INSERT ON t
    FOR EACH ROW
    BEGIN
      IF NEW.qty < 0 THEN
        SIGNAL SQLSTATE '45000' SET MESSAGE_TEXT = 'qty forbids negatives';
      END IF;
    END;
    ```

    Use for validation and defaults.

  </Tabs.Tab>
  <Tabs.Tab>
    Runs after the row lands. `NEW` is read-only here.

    ```sql filename="after" copy
    CREATE TRIGGER t_after_insert AFTER INSERT ON t
    FOR EACH ROW
    BEGIN
      INSERT INTO t_log (ref_id, note) VALUES (NEW.id, 'added');
    END;
    ```

    Use for audit trails and side records.

  </Tabs.Tab>
</Tabs>

## Events and row images

| Event    | `NEW` holds          | `OLD` holds           |
| -------- | -------------------- | --------------------- |
| `INSERT` | Incoming row         | Nothing               |
| `UPDATE` | Row after the change | Row before the change |
| `DELETE` | Nothing              | Removed row           |

```sql filename="events" copy
CREATE TRIGGER t_before_update BEFORE UPDATE ON t
FOR EACH ROW
BEGIN
  IF NEW.amount < OLD.amount THEN
    SET NEW.note = 'discounted';
  END IF;
END;

CREATE TRIGGER t_after_delete AFTER DELETE ON t
FOR EACH ROW
BEGIN
  INSERT INTO t_log (ref_id, note) VALUES (OLD.id, 'removed');
END;

CREATE TRIGGER t_after_update AFTER UPDATE ON t
FOR EACH ROW
BEGIN
  INSERT INTO t_log (ref_id, note) VALUES (NEW.id, 'changed');
END;

CREATE TRIGGER t_before_delete BEFORE DELETE ON t
FOR EACH ROW
BEGIN
  IF OLD.qty > 0 THEN
    SIGNAL SQLSTATE '45000' SET MESSAGE_TEXT = 'nonempty rows resist deletes';
  END IF;
END;
```

<Callout type="info">
  Triggers fire once per affected row, silently. A bulk write fires the body for
  every row it touches.
</Callout>

## Trigger Management

Lists and removes triggers.

```sql filename="management" copy
SHOW TRIGGERS LIKE 't';

DROP TRIGGER IF EXISTS t_before_insert;
```

<Callout type="warning">
  No `COMMIT` or `ROLLBACK` inside triggers. They run inside the firing
  statement's own transaction.
</Callout>
