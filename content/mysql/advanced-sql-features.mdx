# Advanced SQL Features

Advanced features combine earlier topics into heavier machinery. Each section names the feature, shows its shape, and points at the page that owns its depth.

<Steps>

### Add one advanced feature

Pick the single feature the query needs. Measure before adding a second.

Confirm with `EXPLAIN ANALYZE`. Keep the feature only when numbers improve.

## Combining Features

Advanced queries stack features. One recursive walk, ranked per level:

```sql filename="combined" copy
WITH RECURSIVE chain AS (
  SELECT id, parent_id, title, 1 AS depth FROM t WHERE id = 1
  UNION ALL
  SELECT t.id, t.parent_id, t.title, chain.depth + 1
  FROM t
  INNER JOIN chain ON t.parent_id = chain.id
)
SELECT title, depth, ROW_NUMBER() OVER (ORDER BY depth) AS rn FROM chain;
```

<Callout type="warning">
  Advanced never means faster by default. Verify every combination with `EXPLAIN
  ANALYZE`.
</Callout>

<Callout type="info">Everything on this page needs MySQL 8.0 or later.</Callout>
