# String Functions

String functions transform text values. Each takes a string and returns a string.

<Steps>

### Trim edges

Remove leading and trailing spaces with `TRIM`. Clean input before anything else.

### Change case or shape

Normalize with `LOWER` or `UPPER`. Cut or pad with `SUBSTRING`, `LEFT`, `LPAD`.

### Join or extract

Combine with `CONCAT`. Find positions with `LOCATE`. Format numbers with `FORMAT`.

</Steps>

## Joining

Combines strings. The two forms differ on `NULL`.

```sql filename="joining" copy
SELECT CONCAT(title, '!', qty) FROM t;

SELECT CONCAT_WS(' - ', title, note) FROM t;
```

`CONCAT` returns `NULL` if any argument is `NULL`. `CONCAT_WS` skips nulls.

<Tabs items={['CONCAT', 'CONCAT_WS']}>
  <Tabs.Tab>
    Joins all arguments. One `NULL` poisons the result.

    ```sql filename="concat null" copy
    SELECT CONCAT(title, NULL, qty) FROM t;
    ```

    Returns `NULL`. Wrap nullable columns with `COALESCE` when the result must survive.

  </Tabs.Tab>
  <Tabs.Tab>
    Joins with a separator. Skips `NULL` arguments.

    ```sql filename="concat ws" copy
    SELECT CONCAT_WS(' - ', title, NULL, qty) FROM t;
    ```

    Returns the joined non-null parts. Use for display strings over nullable columns.

  </Tabs.Tab>
</Tabs>

<Callout type="warning">
  `CONCAT` with any `NULL` argument returns `NULL`. Use `CONCAT_WS` or wrap
  columns with `COALESCE`.
</Callout>

## Measuring

Counts length. Bytes and characters differ under multibyte encodings.

```sql filename="measuring" copy
SELECT LENGTH(title), CHAR_LENGTH(title) FROM t;
```

`LENGTH` counts bytes. `CHAR_LENGTH` counts characters.

## Case

Changes letter case.

```sql filename="case" copy
SELECT LOWER(title), UPPER(title) FROM t;
```

## Trimming

Removes spaces from edges.

```sql filename="trimming" copy
SELECT TRIM(title) FROM t;

SELECT LTRIM(title), RTRIM(title) FROM t;
```

`TRIM` cuts both sides. `LTRIM` cuts leading spaces. `RTRIM` cuts trailing spaces.

## Extracting

Cuts parts out of a string. Positions start at 1.

```sql filename="extracting" copy
SELECT SUBSTRING(title, 1, 3) FROM t;

SELECT LEFT(title, 3), RIGHT(title, 3) FROM t;
```

## Finding

Locates a substring. Returns its position, or 0 when absent.

```sql filename="finding" copy
SELECT LOCATE('get', title) FROM t;

SELECT INSTR(title, 'get') FROM t;
```

Argument order flips: `LOCATE(substr, str)` but `INSTR(str, substr)`.

<Callout type="info">
  `LOCATE` and `INSTR` take arguments in opposite order. Check the order before
  trusting a position.
</Callout>

## Shaping

Replaces, reverses, and pads strings.

```sql filename="shaping" copy
SELECT REPLACE(title, 'a', 'o') FROM t;

SELECT REVERSE(title) FROM t;

SELECT LPAD(title, 10, '-'), RPAD(title, 10, '-') FROM t;
```

`LPAD` pads on the left. `RPAD` pads on the right. Both cut when the value already exceeds the length.

## Formatting

Rounds a number and returns a locale-formatted string.

```sql filename="formatting" copy
SELECT FORMAT(amount, 2) FROM t;
```
